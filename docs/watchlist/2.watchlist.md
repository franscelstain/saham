# Watchlist — Index & SOP (Non‑binding)

Dokumen ini adalah **index + SOP** untuk fitur Watchlist.  
Aturan yang **mengikat (CONTRACT/LOCKED)** ada di **`docs/watchlist/1.contract.md`** dan dokumen policy.

## Guardrails (CONTRACT snippets)

Ini **bukan** pengulangan kontrak lengkap, tapi *anchor text* untuk test parity dan mencegah salah tafsir unit.

- `score_total` (fraction, range [0..1])
- Group Semantics (Option A)
- `top_cut = max(TOPPICK_MIN_SCORE, S0 - TOPPICK_SCORE_GAP)`

Config keys (no hardcoded numbers):

- `config('trade.watchlist.group_semantics.toppick_min_score')` / `WATCHLIST_TOPPICK_MIN_SCORE`
- `config('trade.watchlist.group_semantics.toppick_score_gap')` / `WATCHLIST_TOPPICK_SCORE_GAP`
- `config('trade.watchlist.group_semantics.secondary_min_score')` / `WATCHLIST_SECONDARY_MIN_SCORE`
- `config('trade.watchlist.group_semantics.watch_only_min_score')` / `WATCHLIST_WATCH_ONLY_MIN_SCORE`

Rujukan lengkap: `docs/watchlist/1.contract.md` dan `docs/watchlist/2a.group_semantics.locked.md`.

1) **Global contract & data degradation:** `docs/watchlist/1.contract.md` (lihat juga: `docs/watchlist/9.legacy_support.md`)

> Jika ada penjelasan yang terasa “mengunci” di dokumen non‑binding (schema/strategi), **abaikan** dan ikuti `1.contract.md` + policy docs.

## Alur minimal sebelum Watchlist
1) `market-data:*` menghasilkan OHLC canonical (EOD).
2) `trade:compute-eod` menghasilkan indikator harian.
3) `market_calendar` terisi (manual OK).
4) (Opsional) status manual & `ca_hint` tersedia. Jika missing → berlaku “graceful degradation” sesuai `1.contract.md`.

## Cara menjalankan (contoh)
- Build preopen harian:
  - `php artisan watchlist:scorecard:compute --policy=WEEKLY_SWING --date=YYYY-MM-DD --persist=1`
- Backtest:
  - `php artisan watchlist:backtest --policy=WEEKLY_SWING --from=YYYY-MM-DD --to=YYYY-MM-DD --persist=1`

Catatan:
- Detail field payload dan semantics grouping **jangan diulang di dokumen ini**. Rujuk langsung ke `1.contract.md` + `policy/*.md`.
