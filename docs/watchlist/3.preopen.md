# WATCHLIST Preopen Contract (LOCKED)

Dokumen ini **CONTRACT** untuk payload PLAN (preopen). Aturan umum seperti `LOCKED/CONTRACT`, `reasons[]`, dan *Data Degradation Rules* mengikuti `docs/watchlist/1.contract.md`.


Dokumen ini mendefinisikan output JSON dari endpoint `GET /watchlist/preopen`.

## Stream alasan (LOCKED)

Ada dua jenis `reasons[]` yang berbeda dan **tidak boleh dicampur** (rujuk `docs/watchlist/1.contract.md`):

1) **Meta reasons**: `meta.*.reasons[]`  
   Dipakai untuk status pipeline hari itu (mis. EOD belum siap, coverage rendah, rekomendasi tidak bisa dibentuk, dll).  
   - Code boleh `GL_*` atau prefix modul lain (`RECO_*`, `ALLOC_*`, dst).  
   - Severity boleh `INFO|WARN|ERROR` (field: `severity`).  
   - Tidak mengubah skor/grup ticker secara langsung.

2) **Candidate reasons**: `groups.*[].items[].reasons[]`  
   Dipakai untuk alasan per ticker (scoring/guard/block/exclude).  
   - Code mengikuti *Candidate Reasons (LOCKED)*: policy-scoped `WS_*`/`DS_*`/`PT_*`/`IL_*` atau global `GL_*`.
   - Candidate reasons wajib pakai `severity_level` (INFO/WARN/SOFT_BLOCK/HARD_EXCLUDE). Jangan pakai `ERROR` untuk candidate.

## Catatan tanggal

Kontrak memakai 2 tanggal:
- `meta.trade_date` = tanggal eksekusi (hari bursa yang sedang/akan dieksekusi).
- `meta.asof_eod_date` = tanggal EOD yang dipakai untuk scoring/ranking (biasanya hari bursa sebelumnya).

## Catatan score_total

- `score_total` adalah float **range [0..1]** (bukan 0..100).
- Jika UI mau tampilkan persentase, UI yang mengalikan `score_total*100`.

## Recommendations

> **Catatan (ANTI SALAH TAFSIR)**
> - `weight_pct` adalah **fraction 0..1** (contoh: 0.20 = 20%). UI boleh menampilkan dalam persen, tapi payload tetap 0..1.

>
> **Reason schema (ANTI SALAH TAFSIR, LOCKED)**
> - `recommendations.reasons[]` dan `recommendations.skipped[].reason` memakai **GlobalReason** ⇒ field `severity` (`INFO|WARN|ERROR`)
> - `recommendations.items[].reasons[]` dan `execution_slices[].reason` memakai **CandidateReason** ⇒ field `severity_level` (`INFO|WARN|SOFT_BLOCK|HARD_EXCLUDE`)

`confirm` digunakan untuk menilai kelayakan eksekusi intraday berdasarkan snapshot LIVE dan guard dari `docs/watchlist/4.scorecard.md`.

```json
      },
      "recommended_orders": [

          "n": 1,
          "time_window": "09:20",
          "action": "PLACE_LIMIT|WAIT|SKIP",
          "lots": 1,
          "plan_limit_price": 0,
          "plan_price_cap": 0,
          "recommended_limit_price": 0,
          "reasons": [{"code":"CF_PRICE_AT_ASK1_WITHIN_CAP","message":"...","severity_level":"INFO"}],
          "inputs_used": {
            "ask_best": 0,
            "bid_best": 0,
            "spread_pct": 0.0045,
            "snapshot_age_sec": 8
          }
        }

```

Aturan praktis:
- `decision=APPROVE` hanya jika ada minimal 1 tranche `action=PLACE_LIMIT`.
- `decision=DELAY` dipakai untuk kondisi yang bisa membaik (contoh: snapshot stale atau chase melewati cap).
- `decision=REJECT` dipakai untuk kondisi yang tidak layak dieksekusi saat ini (contoh: gap-up terlalu besar, spread terlalu lebar, breakout overextended).

### Corporate Action Hint Handling

Tujuan `ca_hint`: memberi peringatan risiko CA (dividend/split/indikasi) dengan data yang mudah diambil, **tanpa** membuat watchlist “mati” saat data bolong.

**Sumber data (pragmatis):**
- Utama: Yahoo `events=div|split` (jika ada).
- Fallback (opsional): deteksi gap ekstrem dari OHLC (indikasi saja).

**Aturan default (global):**
- `ca_hint` kosong/null → tidak ada informasi → **tidak** memblokir.
- `ca_hint` ada → masuk `reasons[]` sebagai reason object dengan `severity_level=WARN` minimal (contoh code global: `GL_CA_HINT_DIV`).

**Soft-block window (disarankan, per-policy bisa override):**
- Untuk event berisiko gap besar (`SPLIT`, `POSSIBLE_CA`): jika jatuh pada window sekitar `trade_date` (mis. H-1/H/H+1),
  maka set `is_eligible_new_entry=false` dan tambahkan reason `GL_CA_SPLIT_WINDOW`,
  **namun ticker tetap tampil** (minimal `watch_only`).

**Catatan penting:**
- `ca_hint` adalah hint; jangan dijadikan **HARD_EXCLUDE** global.
- Semua efek harus terlihat jelas lewat `reasons[]` (code + message + meta).
