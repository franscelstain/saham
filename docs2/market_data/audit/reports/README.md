# Audit Reports README

Folder ini dipakai untuk menyimpan hasil audit aktual terhadap paket market-data.

## Minimum report contents
- package identity
- layer classification
- summary table PASS / PARTIAL / FAIL
- key findings
- remediation summary
- final verdict

## Suggested naming
- `YYYY-MM-DD_<package-name>_audit_report.md`
- `YYYY-MM-DD_<package-name>_remediation_report.md`
