# Market Data System README

## Purpose
Folder `system/` adalah pintu masuk ringkasan sistem market-data. Folder ini bukan pengganti `book/`, `db/`, `ops/`, atau `tests/`, melainkan peta besar agar pembaca memahami sistem sebelum masuk ke kontrak detail.

## What belongs here
- overview sistem
- boundary sistem
- context and dependencies
- data product map
- runtime flow tingkat atas
- ownership map
- read order

## What does not belong here
- full domain contracts
- detailed schema ownership
- detailed runbook steps
- test vectors / fixtures
- illustrative examples sebagai authority
