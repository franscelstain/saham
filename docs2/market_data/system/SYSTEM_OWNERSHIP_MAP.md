# System Ownership Map

## Folder ownership roles
- `system/` = high-level overview and entry-point companion
- `book/` = normative domain contracts
- `db/` = schema and persistence support contracts
- `ops/` = operational rules and guidance
- `tests/` = proof specification and admission criteria
- `examples/` = illustrative material only
- `evidence/` = archived actual evidence if genuine
- `audit/` = evaluation framework

## Authority rule
Bila terjadi konflik antara overview dan contract, contract menang.

## Misread prevention
Pembaca tidak boleh memperlakukan examples atau evidence archive sebagai owner of behavior kecuali file itu memang secara eksplisit contract/LOCKED owner doc.
