# Database Contracts (Shared)

Folder ini mendokumentasikan kontrak tabel sumber data dan tabel pendukung yang dipakai lintas modul.
Isinya fokus pada **struktur data minimum dan makna kolom** yang harus stabil, terlepas dari nama tabel fisiknya.

Dokumen di sini tidak mendefinisikan algoritma aplikasi; hanya memastikan data yang dibutuhkan tersedia dan konsisten.
